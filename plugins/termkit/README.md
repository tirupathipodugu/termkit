# termkit

The termkit hub. `/tools` lists every tool in the termkit marketplace, marks the ones this Claude Code has on (● on, ○ not installed), and gives the line that installs each of the rest.

## Install

At a Claude Code prompt:

```
/plugin install termkit --marketplace tirupathipodugu/termkit
```

## Use

- `/tools`

The list comes from the marketplace file, so a tool added to the repo shows up after `/plugin marketplace update termkit`.
